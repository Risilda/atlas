# ATLAS — Human v0.11

A personal site for Atlas — eleven months old, and a member of the **first generation that will never remember a world without artificial intelligence**.

Built by his family (with an unreasonable amount of help from AI), themed as an affectionate ML-engineering joke: model card, training-data mix, checkpoint releases, live uptime, RLHF rewards.

**Live:** https://risilda.github.io/atlas/

## Stack

Zero frameworks, zero build step, zero tracking. One hand-written HTML file, vanilla CSS/JS, a service worker for offline mode, and Apple's Vision framework (used during curation to find the three-face shots).

## Editing

Milestones, model-card rows and birth date are marked with `<!-- NOTE -->` comments in `index.html`. Edit, commit, push — GitHub Pages redeploys automatically.

## For mom & dad

- Update `v0.11` → `v1.0` on his first birthday 🎂
- The uptime ticker's `BIRTH` constant is at the top of the `<script>` block
- New photos: drop web-ready JPGs in `assets/originals/` and add a line to `ORIGINALS`
